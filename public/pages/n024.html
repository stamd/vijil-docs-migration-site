Install a Collector

N024 · add · Agent Developer's Guide

N024New pageP1How-toNot started

Proposed content

One complete Collector installation how-to with shared artifact access, network requirements, Target/credential prerequisites, verification, troubleshooting, upgrades, and revocation. Start with a short variant selector and stable heading anchors. Keep Endpoint (macOS/Linux/Windows), Network scanner, Kubernetes, and AWS Cloud API instructions as sections of this page. Retain browser and one-shot coverage with explicit support limitations. Link back to the existing owner discovery workflow rather than duplicating Console Target creation and inventory review.

Acceptance criteria

Each variant names its required artifacts, privileges, credentials, supported environment, enrollment evidence, logs, and failure checks. Endpoint coverage includes WSL limitations and re-enrollment. Network scanning covers routing, daemon mode, and container capabilities. Kubernetes covers RBAC and secret references. AWS covers its confirmed IAM/OIDC setup and whether an LLM key is required. Maintain common setup once; distinguish a running service from successful enrollment. Resolve remaining CLI dependencies only through confirmed supported paths. Split a variant later only when an independent workflow becomes difficult to use or maintain here.
