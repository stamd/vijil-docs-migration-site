Getting started

Documentation migration

A clear path from the proposal to the work.

Keep the three existing documentation tabs. Give every page one clear job, connect related content, and migrate in small, verifiable batches.

This handbook brings together the proposal, architecture, evidence, page decisions, and writing standards. Start with the approach, then explore the implementation detail when you need it.

Recommended reading order

1. Start here →Why the documentation needs to change, the approach, and how to begin.2. Understand Diátaxis →Tutorials, how-to guides, reference, and explanations.3. Review the architecture →How the three tabs work together and where information belongs.4. Proposed documentation tree →The complete target structure and the purpose of every page.5. Explore individual pages →Every existing-page decision and every proposed new page.6. Page templates and links →Templates, required sections, and links between related pages.
